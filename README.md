## About The Project

Welcome to the **DedSec Launcher** - a revolutionary, feature-rich, and highly customizable Android launcher that immerses you in the world of Watch Dogs 2. This project was born from a love for the game's unique "hacktivist" aesthetic. The user interface and experience are meticulously crafted to replicate that vibe, featuring elements like glitch art, Matrix-style effects, terminal interfaces, and a color palette inspired by the game.

Our philosophy is to balance **immersion with functionality**. While we want you to feel like a member of DedSec, the launcher must also be a fast, efficient, and practical tool for your daily life.

## ✨ Features

This launcher is packed with cutting-edge features to bring the hacktivist world to your fingertips.

### 🎨 Advanced Theming & Customization

- **17 Color Schemes**: HackerBlue, MatrixGreen, CyberGreen, NeonPink, ElectricBlue, TerminalAmber, and more!
- **Dynamic Background Effects**: Choose from Grid, Hexagonal, Matrix Rain, Particle Network, or None
- **Customizable Grid Layout**: 3-8 rows × 3-6 columns with adjustable icon sizes (0.5x-2.0x)
- **Animation Controls**: Adjust speed, reduce motion, or disable animations for battery optimization
- **Transparency & Effects**: Particle effects, glitch animations, and customizable UI transparency

### ⚡ Enhanced Home Screen

- **Gesture Controls**: 6 customizable gestures (swipe up/down/left/right, double-tap, long-press)
- **Smart Widgets**: Clock (12h/24h), System Stats (Battery/RAM), ready for Weather integration
- **Dynamic Wallpapers**: Animated backgrounds with multiple stunning effects
- **App Shortcuts**: Drag apps to home screen for quick access

### 💻 Advanced Terminal

- **9 Built-in Commands**: help, clear, list, search, launch, info, uninstall, stats, exit
- **Smart Autocomplete**: Real-time suggestions for commands and app names
- **Command History**: Navigate 50+ previous commands with arrow keys
- **Color-Coded Output**: Green for success, red for errors, white for information
- **Timestamps**: Track when each command was executed
- **App Integration**: Launch and manage apps directly from terminal

### 🚀 Quick Access Features

- **Quick Settings Panel**: One-tap access to 9 system settings (Wi-Fi, Bluetooth, Display, Sound, etc.)
- **Notification Center**: Modern notification interface (ready for notification listener)
- **App Drawer**: Clean, organized grid view of all installed applications
- **System Profiler**: Detailed app information including permissions and package details

### 🎯 Performance & Efficiency

- **Battery Optimization**: Configurable performance modes
- **Reduce Motion**: Accessibility option for smoother experience
- **Lazy Loading**: Efficient rendering of large app lists
- **Memory Management**: Optimized for low memory usage

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

- An Android device running Android 7.0 (Nougat) or newer
- Minimum 2GB RAM recommended

### Installation

1. Download the latest `.apk` file from the [Releases](https://github.com/JeremyLakeyJr/watch-dogs-launcher/releases) page
2. Open the downloaded file on your Android device
3. You may need to allow installation from "Unknown Sources" in your device's security settings
4. Follow the on-screen instructions to complete the installation
5. Press the home button and select "DedSec Launcher" as your default launcher

### First Time Setup

1. **Grant Permissions**: Allow necessary permissions for full functionality
2. **Choose Your Theme**: Select from 17 color schemes in Settings
3. **Configure Gestures**: Customize swipe actions to match your workflow
4. **Select Background**: Choose your favorite animated background effect
5. **Arrange Widgets**: Enable/disable Clock and System Stats widgets

## 🎯 How to Use

### Basic Navigation
- **Swipe Up**: Open app drawer (default)
- **Swipe Down**: Open notifications (default)
- **Double Tap**: Launch terminal (default)
- **Long Press**: Customizable action

### Terminal Commands
```bash
help           # Show all available commands
list           # List all installed apps
search <query> # Search for apps
launch <app>   # Launch an application
info <app>     # Show detailed app information
uninstall <app># Uninstall an application
stats          # Display system statistics
clear          # Clear terminal output
exit           # Close terminal
```

### Customization
1. Open **Settings** (swipe gesture or settings button)
2. Navigate through categories:
   - **Theme Settings**: Colors, animations, effects
   - **Home Screen Layout**: Grid size, icon size, labels
   - **Gesture Controls**: Configure all 6 gestures
   - **Terminal Settings**: History size, autocomplete
   - **Widget Settings**: Clock format, system stats
   - **Performance**: Animation speed, battery optimization
